# Legacy Network — website starter

A Next.js + React Three Fiber studio website starter for `legacynets.xyz`.

## Included
- Cinematic procedural 3D hero scene (no paid 3D assets required)
- Responsive studio landing page and project showcase concepts
- GSAP reveal/scroll animation hooks and Lenis smooth scrolling
- Next.js metadata, canonical URL, Open Graph metadata, robots.txt and sitemap.xml
- Organization JSON-LD structured data
- Reduced-motion CSS support and mobile layout

## Run locally
Requires Node.js 20.9+.

```bash
npm install
npm run dev
```

## Before publishing
1. Replace `hello@legacynets.xyz` with a verified contact address and connect a working enquiry form.
2. Replace concept project descriptions with accurate project status, screenshots, contributions and outcomes. Do not imply unfinished concepts are shipped products.
3. Create a real `/og-cover.jpg` image (1200x630) and favicon.
4. Confirm the domain points to the deployment and choose one canonical host (`https://legacynets.xyz` or `https://www.legacynets.xyz`).
5. Add the domain to Google Search Console and submit `/sitemap.xml`.
6. Add real business contact details, privacy information and any required legal/business disclosures before launch.

The 3D hero uses procedural geometry as a first-pass visual. It should be tested on target phones and tuned before production.
